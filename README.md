# SastaHay

A React-based web application project developed by Mahad Raja.

## Project Overview

SastaHay is a modern frontend application built with React and Bootstrap, designed to provide a clean and responsive user experience. This project is owned and maintained by Mahad Raja.

## Tech Stack

- React
- Create React App
- Bootstrap
- React Router DOM
- Axios
- React Icons

## Features

- Responsive layout
- Route-based navigation
- Reusable UI components
- API integration support
- Modern styling with Bootstrap

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

```bash
npm install
```

### Run the app

```bash
npm start
```

The app will run in development mode and open in your browser at:

```text
http://localhost:3000
```

### Production build

```bash
npm run build
```
